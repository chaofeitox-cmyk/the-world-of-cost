# 灵感与素材 (Ideas)

## 作者的出发点（2026-11-26）
- 万事万物似乎都可以从成本的角度分析、解释。
- 推理是最重要的工具。
- 读者：所有对世界好奇的人；目标：换一个角度重新审视世界，获得新的思维范式。
- 参考《自私的基因》：用独特视角解释世界。

## 《自私的基因》值得借鉴的写法
| 手法 | 在《自私的基因》中 | 本书可以怎么用 |
|---|---|---|
| 一个鲜明的核心比喻 | “自私的”基因、“生存机器” | 为“成本”找一个同样好记的说法 |
| 从源头讲起 | 从原始汤中第一个复制子讲起 | 从最基本的成本（能量、时间）讲起 |
| 由简到繁 | 分子 -> 个体 -> 家庭 -> 社会 -> 文化 | 物理/生命 -> 个人 -> 社会 -> 文化 |
| 思想实验和推理 | 鹰鸽博弈、进化稳定策略 (ESS) | 用推理推出结论，并验证预测 |
| 主动回应反对意见 | 反复澄清“自私”只是比喻 | 说明“成本”不等于“钱”，也不等于冷漠 |
| 最后推向新领域 | 第 11 章提出“模因”(meme) | 最后用成本视角解释文化、观念甚至意义 |

## 需要警惕的风险（批判性思考）
- “万能解释”陷阱：如果什么都能解释，可能等于什么都没解释。需要展示成本视角能做出“预测”，并且有可能被证伪。
- 定义要清楚：“成本”是指钱、能量、时间、机会成本，还是任何形式的“付出”？定义太宽会变得空洞，太窄又解释不了万物。
- 需要一章讨论“成本视角的边界”：它在哪里不好用？这会让全书更可信。

- 大脑重量只占体重的一小部分，却消耗大量能量【待核实：常见说法约 20%】：思考是昂贵的。

- 为什么会形成城市：运输成本和聚集。
- 为什么人会排队、会守信用、会有习惯。
